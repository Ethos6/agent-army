# Template reference

Generated by `army docs` from each template's docstring and metadata.

## Starter agents

### Blog to Podcast Script

Paste a blog or article URL and get a natural two-host podcast script: a cold open, a conversation
that explains the article's ideas with examples, and a recap. It stays faithful to the source and
flags claims the article doesn't support. Pair it with the Podcast Generator template to get audio.

```bash
army run blog-to-podcast "Make a 5 minute episode from https://en.wikipedia.org/wiki/Retrieval-augmented_generation"
```

**Options:** `minutes` (default `5`)  
**Tools:** `fetch_url`  
[source](../templates/starter/blog_to_podcast.py)

### Concept Explainer

Explains any concept at three depths (a 10-year-old, a smart newcomer, a practitioner), using
Wikipedia for grounding, one analogy that actually maps, a worked example, common misconceptions,
and a three-question quiz with answers to check understanding.

```bash
army run concept-explainer "Explain gradient descent"
```

**Tools:** `wikipedia`  
[source](../templates/starter/concept_explainer.py)

### CSV Analyst

Ask a question about a spreadsheet in plain English. The agent reads the real column names first,
then gets every number from a tool (grouped sums, means, min/max and an exact calculator), so the
figures it reports are the figures in your file. File access is sandboxed to ARMY_WORKDIR.

```bash
army run csv-analyst "Which channel drove the most revenue in examples/data/campaigns.csv?"
```

**Tools:** `aggregate_csv`, `calculate`, `describe_csv`, `list_files`  
[source](../templates/starter/csv_analyst.py)

### Decision Helper

Helps you choose between options without fooling yourself. It surfaces the criteria that actually
matter to you, weights them, scores every option with the arithmetic shown, runs a sensitivity
check ("would the winner change if X mattered more?"), and names the cheapest way to reduce
uncertainty before committing.

```bash
army run decision-helper "Should we build our analytics in-house, buy a SaaS tool, or use an open-source stack? Team of 4, budget tight"
```

**Tools:** `calculate`, `web_search`  
[source](../templates/starter/decision_helper.py)

### Email Writer

Describe the situation and what you want to happen. The agent drafts three emails that take
different approaches (for example "gentle nudge", "create urgency", "offer an alternative"), each
with a subject line, and explains the trade-off of each so you can pick.

```bash
army run email-writer "Client is 3 weeks late paying a 4,000 USD invoice; I want payment without hurting the relationship"
```

[source](../templates/starter/email_writer.py)

### Interview Coach

Prepares you for a specific interview. Give it the role and company (and optionally the job post
URL). It researches the company, predicts likely questions across behavioural, technical and
role-specific areas, and gives a model answer outline plus what a strong answer must include.

```bash
army run interview-coach "Product manager interview at a fintech startup, focus on payments"
```

**Options:** `questions` (default `10`)  
**Tools:** `fetch_url`, `web_search`  
[source](../templates/starter/interview_coach.py)

### Translator & Localizer

Translates text so it reads as if written by a native speaker for the target market: it adapts
idioms, units, dates and formality, keeps your brand terms consistent with a glossary, and lists
every place it deliberately changed meaning so a reviewer can check them.

```bash
army run localizer "Localize for Japanese customers: 'Our new plan is a home run - sign up by Friday and save 20%!'"
```

**Options:** `glossary` (default ``)  
[source](../templates/starter/localizer.py)

### Meal Planner

Plans a week of meals around your diet, time and budget, reuses ingredients across days to cut
waste, and produces a consolidated shopping list grouped by aisle with estimated cost. Quantities
and totals are calculated exactly.

```bash
army run meal-planner "Vegetarian, 2 people, 30 minutes max on weekdays, budget 80 USD per week"
```

**Options:** `days` (default `7`)  
**Tools:** `calculate`  
[source](../templates/starter/meal_planner.py)

### Mixture of Models

Sends the same question to several different models independently, then a judge model compares
their answers, keeps what they agree on, resolves disagreements, and writes one answer that is
better than any single response. Choose the models with --opt models=a,b,c.

```bash
army run mixture-of-models "What are the trade-offs between SQL and NoSQL databases for a startup?"
```

**Options:** `models` (default ``), `judge` (default ``)  
**Needs:** API keys for each model you list (or local Ollama models).  
[source](../templates/starter/mixture_of_models.py)

### Resume Tailor

Matches your resume against a job description (file, URL or pasted text). It scores the fit
requirement by requirement, rewrites your bullets to surface relevant evidence you already have,
and lists real gaps honestly. It never invents experience.

```bash
army run resume-tailor "Tailor examples/resumes/candidate_a.md to examples/resumes/job_description.md"
```

**Tools:** `fetch_url`, `read_file`  
[source](../templates/starter/resume_tailor.py)

### Stock Snapshot

One-page snapshot of a listed company: price trend from public market data, recent news found by
web search, and the bull and bear case. Every number comes from a tool. This is research support,
not investment advice, and the agent says so.

```bash
army run stock-snapshot "Give me a snapshot of MSFT"
```

**Options:** `period` (default `1y`)  
**Tools:** `calculate`, `stock_history`, `web_search`  
[source](../templates/starter/stock_snapshot.py)

### Travel Planner

Builds a day-by-day itinerary from your destination, dates, budget and interests. It checks the live
7-day forecast, converts your budget into local currency, researches sights and neighbourhoods, and
puts rainy-day options on days with a high chance of rain.

```bash
army run travel-planner "4 days in Lisbon next week, budget 900 USD, I love food markets and viewpoints"
```

**Tools:** `calculate`, `exchange_rate`, `weather`, `web_search`, `wikipedia`  
[source](../templates/starter/travel_planner.py)

### Link Summarizer

Give it one or more links and get a TL;DR, the key points, notable numbers, and who should read the
original. It quotes sparingly and marks anything that is the author's opinion rather than fact.

```bash

```

**Tools:** `fetch_url`

### Web Data Extractor


## Research agents

### arXiv Scout

Finds the papers that matter on a topic. It runs several arXiv searches with different phrasings,
reads the abstracts, ranks papers by relevance and novelty, and explains each one in plain language
with what it contributes, how it was evaluated, and its limitations.

```bash
army run arxiv-scout "Recent work on small language models running on phones"
```

**Options:** `papers` (default `6`)  
**Tools:** `arxiv_search`  
[source](../templates/research/arxiv_scout.py)

### Deep Research

Multi-round web research for questions that need more than one search. A planner breaks the
question into sub-questions, a researcher searches and reads sources for each (with up to 25 tool
calls), and a writer produces a long-form cited report that grades its own confidence per finding.

```bash
army run deep-research "What is the current state of solid-state batteries for EVs, and when will they reach mass production?"
```

**Options:** `depth` (default `25`)  
**Tools:** `calculate`, `fetch_url`, `web_search`, `wikipedia`  
[source](../templates/research/deep_research.py)

### Fact Checker

Paste a claim, a post or an article. The agent splits it into individual checkable claims, looks for
independent evidence for and against each, and gives a verdict (supported, misleading, false,
unverified) with sources. It distinguishes "no evidence found" from "evidence against".

```bash
army run fact-checker "Check: 'The Great Wall of China is visible from space with the naked eye.'"
```

**Tools:** `calculate`, `fetch_url`, `web_search`, `wikipedia`  
[source](../templates/research/fact_checker.py)

### Literature Review Matrix

Produces a structured literature review: a comparison matrix of papers (method, data, metric,
result, limitation), a synthesis of where the field agrees and disagrees, and research gaps worth
pursuing. Built for students and R&D teams starting a new topic.

```bash
army run literature-review "Literature review on LLM hallucination detection methods"
```

**Tools:** `arxiv_search`, `web_search`, `write_file`  
[source](../templates/research/literature_review.py)

### Market Sizer

Estimates TAM, SAM and SOM two independent ways (top-down from published market data, bottom-up
from customer counts times price), shows every assumption and calculation, and reconciles the two
estimates. Investors and founders get a defensible number instead of a guess.

```bash
army run market-sizer "Market size for AI note-taking apps for doctors in the US"
```

**Tools:** `calculate`, `fetch_url`, `web_search`  
[source](../templates/research/market_sizer.py)

### News Digest

Reads the RSS/Atom feeds you trust (pass them with --opt feeds=url1,url2 or in the task), removes
duplicates across sources, ranks stories by importance to your stated interests, and writes a
five-minute digest with links. Schedule it with `army schedule` for a daily briefing.

```bash
army run news-digest "Digest of https://hnrss.org/frontpage and https://feeds.bbci.co.uk/news/technology/rss.xml for an AI startup founder"
```

**Options:** `feeds` (default ``)  
**Tools:** `fetch_url`, `read_feed`  
[source](../templates/research/news_digest.py)

### Research Brief

Give it a question and a few URLs. It reads each page, pulls out the claims that carry numbers,
dates and names, checks arithmetic with an exact calculator, and writes a brief with four fixed
sections: Bottom line, Key findings (each one cited), What is uncertain, and Sources.

```bash
army run research-brief "Summarize https://en.wikipedia.org/wiki/Large_language_model for a CMO"
```

**Options:** `max_sources` (default `4`)  
**Tools:** `calculate`, `fetch_url`  
[source](../templates/research/research_brief.py)

### Tech Radar

A weekly radar of what developers are actually talking about. It reads the Hacker News front page
and trending discussions, clusters stories into themes, separates hype from substance, and rates
each theme Adopt / Trial / Assess / Hold for your stack.

```bash
army run tech-radar "Tech radar for a Python backend team"
```

**Options:** `stories` (default `30`)  
**Tools:** `fetch_url`, `hacker_news`, `web_search`  
[source](../templates/research/tech_radar.py)

## Business & strategy agents

### Budget Coach

Point it at an export of your spending (CSV with date, category, amount). It computes where the money
goes with exact sums, compares against a 50/30/20 baseline, finds the leaks (subscriptions, delivery,
impulse buys) and builds a realistic savings and debt-payoff plan. Not financial advice.

```bash
army run budget-coach "Analyse examples/data/budget.csv and help me save 500 more per month"
```

**Tools:** `aggregate_csv`, `calculate`, `describe_csv`  
[source](../templates/business/budget_coach.py)

### Competitor Watch

Give it your URL and your competitors' URLs. It reads every page and writes a snapshot table
(positioning in their own words, target customer, exact pricing, recent changes), then where you
win, where you are exposed, and three moves for this quarter, each tied to evidence. It only
reports pricing it actually saw.

```bash
army run competitor-watch "We are https://ourco.com, compare us with https://rival1.com/pricing and https://rival2.com"
```

**Tools:** `calculate`, `fetch_url`  
[source](../templates/business/competitor_watch.py)

### Due Diligence Team

An investment-committee workflow for a startup: a market analyst, a product and technology analyst
and a risk analyst research the company in turn, each building on the earlier sections, then a partner writes the investment
memo with a clear recommendation and the questions to ask the founders.

```bash
army run due-diligence-team "Due diligence on https://www.example-startup.com (seed round, AI for logistics)"
```

**Tools:** `calculate`, `crawl_site`, `fetch_url`, `web_search`  
[source](../templates/business/due_diligence_team.py)

### Startup Idea Validator

Stress-tests a startup idea before you spend months on it. It searches for existing competitors and
failed attempts, estimates who has the problem and how painful it is, scores the idea, and designs
the cheapest experiments to prove or kill it within two weeks.

```bash
army run idea-validator "An app that books last-minute restaurant cancellations for a fee"
```

**Tools:** `calculate`, `fetch_url`, `hacker_news`, `web_search`  
[source](../templates/business/idea_validator.py)

### Investment Comparison

Compares two to five tickers side by side: price performance over several periods from public market
data, recent news, business quality signals and key risks, presented as a comparison table and a
balanced discussion. Research support only, not investment advice.

```bash
army run investment-compare "Compare NVDA, AMD and INTC"
```

**Tools:** `calculate`, `stock_history`, `web_search`  
[source](../templates/business/investment_compare.py)

### Product Launch Intel

Analyses a competitor's product launch (announcement page, docs, press coverage, community
reaction) and tells you what launched, who it targets, how the market reacted, and what it means
for you: threats, opportunities and a recommended response.

```bash
army run launch-intel "Analyse the latest launch from a major note-taking app competitor"
```

**Tools:** `fetch_url`, `hacker_news`, `web_search`  
[source](../templates/business/launch_intel.py)

### Meeting Prep

Before a meeting with a company or person, it researches the organisation's recent news, priorities
and context, then gives you a one-page brief: who they are, what they likely care about, talking
points, questions to ask, and landmines to avoid.

```bash
army run meeting-prep "Sales meeting with the head of operations at a mid-size logistics company; we sell route-optimization software"
```

**Tools:** `crawl_site`, `fetch_url`, `web_search`  
[source](../templates/business/meeting_prep.py)

### OKR Coach

results measurable outcomes (not task lists), flags sandbagging and vanity metrics, and adds the
leading indicators and weekly check-in questions that keep the team honest.

```bash
army run okr-coach "Our goals: improve the onboarding, get more enterprise customers, make the app faster"
```

[source](../templates/business/okr_coach.py)

### Pricing Analyst

Designs or reviews pricing. It collects competitor price points, maps your value metric, models

### Customer Review Insights

```bash
army run review-insights "What should we fix first? examples/data/reviews.csv"
```

**Tools:** `aggregate_csv`, `calculate`, `describe_csv`, `read_file`  
[source](../templates/business/review_insights.py)

### Sales Battlecard

Builds a competitive battlecard a sales rep can use mid-call: how the competitor positions itself,
where we win and lose, landmine questions to plant, objection handling with proof points, and a
pricing comparison taken from their public pages.

```bash
army run sales-battlecard "Battlecard for our product https://ourco.com against https://competitor.com"
```

**Tools:** `calculate`, `fetch_url`, `web_search`  
[source](../templates/business/sales_battlecard.py)

### Strategy Consultant

Works a business problem the way a top-tier consultant would: frames the real question, builds an

## Marketing & content agents

### Ad Copy Variants

Writes ad variants built for testing, not just rewording: each variant tests one distinct angle
(pain, outcome, social proof, urgency, objection-busting) and respects the platform's character
limits, which are checked exactly. Includes a test plan saying what each variant should teach you.

```bash
army run ad-variants "Search ads for an online bookkeeping service for freelancers"
```

**Options:** `variants` (default `6`)  
**Tools:** `fetch_url`, `text_stats`  
[source](../templates/marketing/ad_variants.py)

### Brand Voice Checker

Checks a draft against your brand voice. It learns the voice from your existing pages or a
guidelines file, scores the draft on each voice attribute with quoted evidence, flags banned or
off-brand phrases, and returns a corrected version with every change explained.

```bash
army run brand-voice-checker "Check this against the voice of https://www.python.org: 'Unlock synergies with our revolutionary paradigm!'"
```

**Tools:** `fetch_url`, `read_file`  
[source](../templates/marketing/brand_voice_checker.py)

### Content Team

Three specialists run in order. A strategist reads your source material and writes a creative brief
(audience, proof points, hooks, tone), a writer drafts the piece to the brief, and an editor tightens
it, checks every claim against the brief, and returns publish-ready copy with edit notes.

```bash
army run content-team "Announce our new open-source agent framework to developers"
```

**Options:** `channel` (default `LinkedIn post`)  
**Tools:** `fetch_url`  
[source](../templates/marketing/content_team.py)

### Landing Page Critic

Audits a landing page like a conversion-rate expert. It reads the page and checks the five-second
test, value proposition, proof, objections, call to action and friction, scores each area, and
gives rewritten copy for the weakest parts plus A/B tests ranked by expected impact.

```bash
army run landing-page-critic "Critique https://www.python.org as a landing page for new developers"
```

**Tools:** `fetch_url`, `text_stats`  
[source](../templates/marketing/landing_page_critic.py)

### Newsletter Writer

Turns a set of links, notes or feeds into an issue people actually open and read: a subject line
tested against alternatives, a sharp intro, curated items with the "so what" for your readers, and a
single call to action. It keeps a consistent structure issue to issue.

```bash
army run newsletter-writer "Write this week's issue for product managers from https://hnrss.org/frontpage"
```

**Options:** `audience` (default ``)  
**Tools:** `fetch_url`, `read_feed`  
[source](../templates/marketing/newsletter_writer.py)

### Press Release Writer

Writes a news-ready press release in standard format: headline, dateline, inverted-pyramid lead,
supporting facts, a spokesperson quote that says something real, boilerplate and media contact
placeholders. It also drafts a short pitch email to journalists and flags any claim needing proof.

```bash
army run press-release "We raised a 5M seed round to build AI bookkeeping for restaurants; launching in 3 cities"
```

**Tools:** `fetch_url`  
[source](../templates/marketing/press_release.py)


**Options:** `audience` (default ``)  
**Tools:** `fetch_url`, `read_file`  
[source](../templates/marketing/reader_panel.py)

### SEO Content Brief

### Social Media Calendar

## Engineering & coding agents

### API Docs Writer

Reads your source code and writes developer documentation from what the code actually does: an
overview, every public function or endpoint with parameters, return values, errors and a runnable
example. It flags undocumented behaviour and inconsistencies it found, and saves the docs to
outputs/.

```bash
army run api-docs-writer "Document the public API of army/memory.py"
```

**Tools:** `list_files`, `read_file`, `write_file`  
[source](../templates/engineering/api_docs_writer.py)

### Architecture Reviewer

Reviews a codebase or a design document like a principal engineer. It maps the components and data
flow, then evaluates scalability, reliability, security, operability and cost, names the single
points of failure, and proposes a prioritized list of changes with effort estimates and a Mermaid
diagram of the current architecture.

```bash
army run architecture-reviewer "Review the architecture of this repository"
```

**Tools:** `list_files`, `read_file`, `web_search`  
[source](../templates/engineering/architecture_reviewer.py)

### Bug Triage

Paste a bug report, stack trace or error log. The agent reproduces the reasoning a senior on-call
engineer would: it locates the relevant code, forms ranked hypotheses for the root cause, says how
to confirm each one, proposes a fix, and assigns severity and a regression test.

```bash
army run bug-triage "Traceback: ZeroDivisionError in avg() at stats.py line 12 when the report has no rows"
```

**Tools:** `git_log`, `list_files`, `read_file`, `web_search`  
[source](../templates/engineering/bug_triage.py)

### Code Reviewer

Run it inside any git repo. It reads the diff, opens surrounding files when it needs context, and
reports only the problems that matter, each with a severity, the exact input that triggers it and
the smallest fix. It ends with a machine-readable verdict you can gate CI on.

```bash
army run code-reviewer "Review my uncommitted changes"
```

**Options:** `ref` (default `HEAD`)  
**Tools:** `git_diff`, `list_files`, `read_file`  
[source](../templates/engineering/code_reviewer.py)

### Commit Explainer

Answers "why does this code exist?". Point it at a file or a line range and it walks the git history:
the commit that introduced the code, later changes, what changed alongside it, and the messages and
diffs that reveal intent. It separates what the history proves from what it only suggests.

```bash
army run commit-explainer "Why does army/agent.py parse JSON from code fences?"
```

**Tools:** `git_blame`, `git_log`, `git_show`, `read_file`  
[source](../templates/engineering/commit_explainer.py)

### Dependency Auditor

Checks a Python requirements file against live PyPI data: outdated pins, yanked releases,
backport packages that are obsolete on modern Python, standard-library modules listed as
dependencies, unpinned entries and conflicting duplicate constraints. Every finding comes with
the fix.

```bash
army run dependency-auditor "Audit examples/data/requirements-sample.txt for Python 3.12"
```

**Tools:** `pypi_package`, `read_file`  
[source](../templates/engineering/dependency_auditor.py)

### Incident Postmortem Writer

Turns raw incident notes, chat logs and timelines into a blameless postmortem: impact with numbers,
a clean timeline, root cause using the five whys, what went well, where we got lucky, and action
items that each have an owner placeholder, a due date and a type (prevent, detect, mitigate).

```bash
army run postmortem-writer "14:02 deploy v2.3; 14:05 error rate 30%; 14:20 paged; 14:41 rollback; 14:45 recovered. Cause: missing DB index"
```

**Tools:** `calculate`, `read_file`  
[source](../templates/engineering/postmortem_writer.py)

### Scope Creep Checker

Compares a diff with its stated intent (the PR title or ticket). It groups every change into
"needed for the intent", "related but separable" and "unrelated", and recommends what to keep, split
into another PR, or justify, so reviews stay small and history stays readable.

```bash
army run scope-checker "Intent: fix the login redirect bug. Check my uncommitted changes"
```

**Options:** `ref` (default `HEAD`)  
**Tools:** `git_diff`, `read_file`  
[source](../templates/engineering/scope_checker.py)

### SQL Assistant

Ask questions about a SQLite database in plain English. The agent reads the schema, writes the SQL,
runs it read-only, checks that the result makes sense, and answers with the number, the query it
used and a short explanation. Write queries are refused by the tool itself, not just the prompt.

```bash
army run sql-assistant "Which product category earned the most revenue in examples/data/shop.db?"
```

**Options:** `db` (default `examples/data/shop.db`)  
**Tools:** `calculate`, `sql_query`, `sql_schema`  
[source](../templates/engineering/sql_assistant.py)

### Test Writer

Reads a source file and writes a thorough test file for it: happy paths, edge cases, error handling
and regression cases derived from the code's actual branches. It explains which behaviours are
covered and what it deliberately skipped, and saves the test file to outputs/.

```bash
army run test-writer "Write unittest tests for army/rag.py"
```

**Options:** `framework` (default `unittest`)  
**Tools:** `list_files`, `read_file`, `write_file`  
[source](../templates/engineering/test_writer.py)

## Multi-agent teams

### Debate Panel

Stress-tests a decision or claim through structured debate. An advocate builds the strongest case
for, a critic builds the strongest case against (both with web evidence), and a neutral moderator
weighs the arguments, identifies the cruxes and gives a verdict with its confidence. Each side can
run on a different model with --opt models=a,b,c.

```bash
army run debate-panel "Should our 20-person startup move from a monolith to microservices?"
```

**Options:** `models` (default ``)  
**Tools:** `web_search`  
[source](../templates/teams/debate_panel.py)

### Design Review Panel

Three expert reviewers critique a web page or product description independently (a usability
expert, an accessibility expert and a visual and brand designer), then a design lead merges their
findings into one prioritized list with severity, so you get the breadth of a panel without the
meeting.

```bash
army run design-review-panel "Review https://www.python.org"
```

**Tools:** `fetch_url`  
[source](../templates/teams/design_review_panel.py)

### Finance Research Team

A manager agent delegates to two specialists: a market-data analyst that pulls price history and
computes returns, and a news analyst that gathers recent developments. The manager decides what to
ask each one, merges their work, and writes the final note. A small example of hierarchical,
manager-and-workers orchestration.


## RAG (retrieval-augmented generation)

### Citation-Checked RAG

Two agents keep each other honest. An answerer writes a cited answer from the docs; a verifier then
re-retrieves every cited passage and checks that it really supports the sentence it's attached to,
removing or correcting anything unsupported. You get the verified answer and an audit table.

```bash
army run citation-checker "Summarize our refund and discount policies"
```

**Options:** `docs` (default `examples/knowledge-base`)  
**Tools:** `search_docs`  
[source](../templates/rag/citation_checker.py)

### Corrective RAG

Retrieval that checks itself before answering. After each search it grades every passage as
relevant, partial or irrelevant; if the evidence is weak it rewrites the query and searches again,
and as a last resort falls back to web search, clearly labelling which facts came from the web.

```bash
army run corrective-rag "How do I rotate an API key, and how quickly do revoked keys stop working?"
```

**Options:** `docs` (default `examples/knowledge-base`), `web_fallback` (default `yes`)  
**Tools:** `search_docs`, `web_search`  
[source](../templates/rag/corrective_rag.py)

### Docs Q&A

Point it at a folder of Markdown, text or code. It builds a BM25 index in memory (milliseconds, no
vector database, no embedding API) and answers questions with a citation on every claim, like
[pricing.md:3-12]. It refuses when the answer isn't in the docs, and that refusal is tested.

```bash
army run docs-qa "What is the refund window on the Pro plan?"
```

**Options:** `docs` (default `examples/knowledge-base`)  
**Tools:** `search_docs`  
[source](../templates/rag/docs_qa.py)

### FAQ Builder

Reads a documentation folder and writes the FAQ your users actually need: it predicts the questions
real customers ask, answers each from the docs with citations, flags questions the docs can't answer
(content gaps), and saves the FAQ as Markdown ready for your help centre.

```bash
army run faq-builder "Build an FAQ from examples/knowledge-base"
```

**Options:** `docs` (default `examples/knowledge-base`)  
**Tools:** `list_files`, `read_file`, `search_docs`, `write_file`  
[source](../templates/rag/faq_builder.py)

### Entity Graph RAG

Answers multi-hop questions ("which plan includes the feature that the security page says needs
SSO?") by building a lightweight entity graph over your documents: capitalised terms, numbers with
units and defined terms become nodes, and passages that mention them together become edges. The
agent hops entity to entity and cites every passage it used.

```bash
army run graph-rag "Which plan has the uptime SLA, and what else does that plan include?"
```

**Options:** `docs` (default `examples/knowledge-base`)  
**Tools:** `passages_about`, `related_entities`, `search_docs`  
[source](../templates/rag/graph_rag.py)

### Hybrid Search RAG

Combines keyword search (BM25, great for exact names, codes and numbers) with semantic search
(embeddings, great for paraphrases) using reciprocal-rank fusion. Embeddings come from
ARMY_EMBED_MODEL (OpenAI, Gemini or a local Ollama model) and are computed lazily on the first
question.

```bash
army run hybrid-rag "Can students get a discount, and how much?"
```

**Options:** `docs` (default `examples/knowledge-base`), `embed_model` (default ``)  
**Tools:** `search_docs`  
**Needs:** An embedding model: OPENAI_API_KEY, GEMINI_API_KEY, or Ollama with nomic-embed-text.  
[source](../templates/rag/hybrid_rag.py)

### Multi-Source Router

Answers across several separate knowledge bases (for example product docs, HR policies and
engineering wikis). Each source gets its own search tool; the agent routes each question to the
right one, searches more than one when the question spans them, and says which source every fact
came from.

```bash
army run multi-source-router "What does Pro cost, and how many remote days a week can employees work?"
```

**Options:** `sources` (default `product=examples/knowledge-base,hr=examples/hr-policies`)  
**Tools:** `search_hr`, `search_product`  
[source](../templates/rag/multi_source_router.py)

### Query Rewriting RAG

Users ask vague or multi-part questions. This agent first decomposes the question into atomic
sub-questions and rewrites each into keyword-rich search queries, retrieves for every one, and then
composes a single answer that addresses each part with citations.

```bash
army run query-rewrite-rag "We're a non-profit thinking about annual Pro billing - what would we pay and what security do we get?"
```

**Options:** `docs` (default `examples/knowledge-base`)  
**Tools:** `search_docs`  
[source](../templates/rag/query_rewrite_rag.py)

### Retrieval Clinic

Diagnoses why a RAG system gives bad answers. Give it a few questions and the expected answers; it
runs retrieval for each, inspects the ranked passages and scores, and classifies each failure
(missing content, chunking split, vocabulary mismatch, ranking noise, ambiguous question) with a
concrete fix.

```bash
army run retrieval-clinic "Q: refund window for Pro? expected: 30 days. Q: SSO on which plan? expected: Enterprise. Q: SOC 2 report? expected: unknown"
```

**Options:** `docs` (default `examples/knowledge-base`)  
**Tools:** `inspect_retrieval`  
[source](../templates/rag/retrieval_clinic.py)

### Semantic RAG

Pure embedding search over your documents: questions match by meaning even when they share no words
with the text ("can I get my money back?" finds the refund policy). Uses ARMY_EMBED_MODEL and keeps
vectors in memory, so there is no vector database to run.

```bash
army run semantic-rag "Can I get my money back if I change my mind?"
```

**Options:** `docs` (default `examples/knowledge-base`), `embed_model` (default ``)  
**Tools:** `search_docs`  
**Needs:** An embedding model: OPENAI_API_KEY, GEMINI_API_KEY, or Ollama with nomic-embed-text.  
[source](../templates/rag/semantic_rag.py)

### Database + Docs Router

Some questions need numbers from a database, others need policy from documents, and some need
both ("how much did India spend, and do they qualify for a discount?"). This agent decides per
question whether to query SQL (read-only), search the docs, or combine them, and cites both kinds of
evidence.

```bash
army run sql-docs-router "How many orders did customers in India place, and what annual-billing discount could they get?"
```

**Options:** `db` (default `examples/data/shop.db`), `docs` (default `examples/knowledge-base`)  
**Tools:** `calculate`, `search_docs`, `sql_query`, `sql_schema`  
[source](../templates/rag/sql_docs_router.py)

## Cost & context optimization

### Context Compressor

Cuts the tokens you send to expensive models. It rewrites long documents, logs or chat histories
into dense notes that keep every fact, number, name, decision and open question while dropping
filler, then reports the compression ratio. Feed the result to a bigger model to save cost.

```bash
army run context-compressor "Compress examples/talks/keynote.vtt for later use as context"
```

**Tools:** `fetch_url`, `read_file`, `text_stats`, `write_file`  
[source](../templates/optimize/context_compressor.py)

### Prompt Optimizer

Improves a prompt by testing it, not guessing. It writes a few test inputs, runs your original
prompt and two rewritten candidates on the configured model, scores each output against the stated
goal, and returns the winning prompt with the evidence and a shorter variant that saves tokens.

```bash
army run prompt-optimizer "Optimize: 'Summarize this customer email.' Goal: 2-line summary with sentiment and the action needed"
```

**Tools:** `run_prompt`  
[source](../templates/optimize/prompt_optimizer.py)

## Fine-tuning & dataset builders

### Fine-tuning Dataset Builder

Turns a folder of your documents into a fine-tuning dataset: diverse, realistic instruction/response
pairs grounded in the text (with no facts that aren't in the source), saved as chat-format JSONL that
common fine-tuning tools accept. It also writes a held-out evaluation split.

```bash
army run dataset-builder "Build 20 training examples from examples/knowledge-base for a support assistant"
```

**Options:** `docs` (default `examples/knowledge-base`)  
**Tools:** `list_files`, `read_file`, `search_docs`, `write_file`  
[source](../templates/finetune/dataset_builder.py)

### Eval Case Builder

Writes evaluation cases for any Agent Army template (or your own agent). It reads the template's
source to understand its job and output format, then proposes test inputs covering the happy path,
edge cases and must-refuse cases, with must_contain checks you can paste straight into EVALS.

```bash
army run eval-builder "Write eval cases for templates/rag/docs_qa.py"
```

**Options:** `cases` (default `6`)  
**Tools:** `list_files`, `read_file`  
[source](../templates/finetune/eval_builder.py)
